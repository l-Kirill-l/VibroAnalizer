# VibroAnalyzer v3 — анализаторы, запись и воспроизведение

## Каталог анализаторов

В приложении 34 анализатора. Они сгруппированы по категориям, каждый пункт
каталога содержит краткое описание, а кнопка «?» в окне анализатора открывает
подробную справку: формулы, допущения, порядок применения и ограничения.

## Физические основы и стандарты

- **Осциллограф** — Vpp = max−min, СКЗ = sqrt(mean x²), частота по переходам
  через ноль с гистерезисом. Для сложных сигналов используйте спектр.
- **Спектр** — БПФ с окном Ханна; амплитуда `2|X[k]|/Σw` (кроме DC/Найквиста),
  уровни в дБFS, ENBW = 1.5. Разрешение Δf = fs/N.
- **Третьоктавные полосы** — IEC 61260-1: точные центры
  `fc = 1000·10^(n/10)`, границы `fc·10^(±1/20)`.
- **Уровень звука** — IEC 61672: весовые функции A и C, нормировка 0 дБ на
  1 кГц. Значения в дБFS; для дБ SPL нужна калибровка микрофона.
- **Welch PSD** — сегменты с окном Ханна и 50 % перекрытием; PSD =
  `|X|²/(fs·Σw²)` с удвоением положительных частот. Усреднение снижает
  разброс, но не улучшает разрешение; zero-padding не заменяет длинный сегмент.
- **Leq** — энергетическое среднее `10log10(mean x²)`, а не среднее децибел;
  LAeq/LCeq — с весами IEC 61672. Это Leq текущего окна, не интеграл за сессию.
- **Спектр огибающей** — полосовой фильтр вокруг резонанса, аналитический
  сигнал через преобразование Гильберта, БПФ огибающей. Ширина полосы и длина
  записи критичны; при переменных оборотах нужен порядковый анализ.
- **Переходы через ноль** — ZCR = N/T, для синуса f ≈ ZCR/2; обязательны
  удаление DC и гистерезис, иначе шум даёт ложные переходы.
- **Шумовой пол/SNR** — процентили кратковременных СКЗ; это статистическая
  оценка, а не стандартный шумомер.
- **THD** — стандартное отношение СКЗ гармоник к СКЗ основной:
  `THD = sqrt(Σ A_h²)/A_1`, h = 2…10. THD+N вычитает суммарную мощность
  главного лепестка основной частоты (±4 бина), а не один пиковый бин.
- **RT60** — метод Schroeder: перед интегрированием удаляются DC и шумовой пол;
  `EDC(t)=∫_t^∞ (h−μ)²−P_noise dτ`, наклон −5…−35 дБ (T30) или
  −5…−25 дБ (T20), `RT60 = −60/наклон` (идея ISO 3382).
- **Кепстр** — `IFFT(log|FFT(xw)|)`; пик модуля кефренции (после 2 мс)
  соответствует периоду гармонического комплекса. Для чистого тона результат 0.
- **Огибающая** — `LPF(|x|)`; выбор среза между частотой модуляции и несущей.
- **Куртозис/эксцесс** — `m4/σ⁴`; для гауссова шума 3, эксцесс = куртозис−3.
  В вибрационной диагностике рост куртозиса выше 3 указывает на импульсы.
- **Подшипники** —
  `BPFO=(N/2)fr(1−d/D·cosφ)`, `BPFI=(N/2)fr(1+d/D·cosφ)`,
  `BSF=(D/2d)fr(1−(d/D·cosφ)²)`, `FTF=(fr/2)(1−d/D·cosφ)`.
  Множители нужно брать из геометрии конкретного подшипника.
- **Балансировка** — синхронное детектирование 1×:
  `I=2Σxw·sin/Σw`, `Q=2Σxw·cos/Σw`, `A=√(I²+Q²)`, `φ=atan2(Q,I)`.
- **STA/LTA** — отношение средних энергий в коротком и длинном окнах;
  триггер с гистерезисом. Длинное окно должно помещаться в окно анализа.
- **Ариас** — `Ia = π/(2g)·∫a²dt`; вход должен быть ускорением в м/с².
- **Спектр реакции** — линейный осциллятор
  `ü+2ζωu̇+ω²u=−a_g`, метод Ньюмарка, `Sa=ω²·max|u|`.
- **Пульс** — пики огибающей, RR-интервалы, `HR=60000/RR_ср`.
- **ЭМГ** — полосовой фильтр 20–450 Гц и режекция 50/60 Гц до RMS/спектра.
- **ЭЭГ** — delta 0.5–4, theta 4–8, alpha 8–13, beta 13–30, gamma 30–45 Гц.

## Запись

Запись включается кнопкой «Записать сессию» (все входы, виртуальные входы и
выходы) или кнопкой «Запись» у конкретного входа/микшера. Демодулированные
сигналы записываются отдельно от сырых, мониторы выходов — отдельно.

Каталог создаётся автоматически:

```
SharedSessionData/<moduleId>/recordings/<yyyyMMdd-HHmmss>-<name>/
  manifest.json
  bus-01-raw.wav
  bus-01-demod.wav
  bus-02-raw.wav
  out-01-monitor.wav
```

Формат WAV — моно IEEE float32; `manifest.json` содержит имя, время,
частоту дискретизации, длительность и список шин. Запись использует только
новые отсчёты (`TotalFramesWritten`), поэтому не дублирует данные.

## Воспроизведение

«Открыть запись...» в главном окне или запуск:

```bash
dotnet run --project src/VibroAnalyzer.App -- --replay /путь/к/записи
```

В окне воспроизведения доступны:

- play/pause/stop, перемотка слайдером, скорость 0.25×…4×;
- список записанных шин;
- осциллограф, спектр, каталог анализаторов и наложение для каждой шины.

Данные при воспроизведении берутся только из файлов; физические устройства
не используются. Окна анализаторов работают так же, как в живом режиме.

## Демо-режим и конструктор

Демо-режим вынесен в окно «Настройки» (кнопка в правом верхнем углу).
В нём задаются тоны: частота, амплитуда, форма (синус/прямоугольник/
треугольник), канал (−1 — все) и общий уровень шума. В демо-режиме
используется только синтезированный сигнал конструктора; реальные
устройства не задействованы. При выключении демо-режима приложение
возвращается к нативным устройствам PipeWire/WASAPI.

## Фильтрация в анализаторах

Фильтры медицинских анализаторов — **отключаемые настройки**, а не жёстко
зашитая обработка. В окне анализатора в разделе «Параметры» есть чекбоксы:

- полосовой фильтр;
- режекция 50 Гц;
- режекция 60 Гц.

Границы полосы задаются в герцах. Значения по умолчанию:

- пульс: 0.5–10 Гц, огибающая 5 Гц;
- дыхание: 0.05–1 Гц;
- ЭЭГ: 0.5–45 Гц;
- ЭМГ: 20–450 Гц.

При отключении фильтра сырой сигнал подаётся непосредственно в детектор или
спектр. Огибающая пульса по-прежнему сглаживается ФНЧ; его срез настраивается.
В справке каждого анализатора указано, какие артефакты появляются при
отключении фильтров.

## Ограничения

- Спектр и полосовые уровни без калибровки — относительные дБFS, не дБ SPL.
- RT60 и спектр реакции требуют корректного импульсного/сейсмического входа;
  непрерывный сигнал даёт лишь оценку.
- Ариас и PGA требуют калиброванного акселерометра в м/с².
- Медицинские анализаторы не являются медицинскими приборами и не заменяют
  диагностику.
- Кросс-спектр, когерентность и передаточная функция требуют одновременно
  двух шин; в текущей версии не реализованы.
- Спектрограмма (водопад) пока не выведена отдельным окном.
